# better-todo-list

Lightweight, elegant and completely free to-do list application for macOS.

## Features

+ Competely free with no in-app purchases
+ Designed and built natively for Apple Silicon
+ Lightweight in size (656 KB)
+ Compact sidebar mode
+ Sleek and elegant design inspired from frosted glass

## Setup guide

To install and run this app, you have to be running **macOS 27.0 Golden Gate** or higher.

1. Download the [latest release](https://github.com/mxphwd/better-todo-list/releases).
2. Extract the .zip file and move the .app file to Applications folders or whichever folder you are comfortable running the application in.
3. Double-click the .app file to open.
4. Click "OK" to dismiss the warning.
5. Open **System Settings** and navigate to **Privacy & Security**
6. Scroll down to find the section stating *"better-todo-list" was blocked to protect your Mac*.
7. Click **Open Anyway**
8. Authenticate using Touch ID or your Mac password.
